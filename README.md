EiffelStudio 22.05
==================

This is a port of EiffelStudio 22.05 built with GCC15 for macosx-armv6. It is based on the [PorterPackage](https://github.com/tioui/EiffelStudio-GPL-Releases/releases/download/v22.05/PorterPackage.tar.bz2) patched to compile using MacPorts on macOS Tahoe. The compiler works, but the EiffelStudio IDE crashes sometimes.

The 24.05 directory contains build scripts and patches to compile [EiffelStudio 24.05](https://github.com/EiffelSoftware/EiffelStudio).

**NOTE**: Install EiffelStudio via MacPorts (sudo port install eiffelstudio) or use the [EiffelStudio](https://account.eiffel.com/downloads) stable versions provided by Eiffel Software. Otherwise here is the code. Good luck!
